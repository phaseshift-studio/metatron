    area geometry=>real /m/math/geo/inst/area 
    area?real<=geometry(){<j>}

    mapper the \(2\)-dimensional measure of the polygonal part: shells positive, holes negative, by the planar shoelace formula scaled at the polygon's mean latitude — tight for parcels and districts, wrong for continents one-to-one obj transformation (dom_c = rng_c = 1)

    the lhs geometry => its area in square meters, as a plain \(\mathrm{real}::T\) (\(\mathrm{math}\) has no squared-length unit type)
    examples: 
    geo:polygon::[[[-123.2,44.4],[-122.9,44.4],[-122.9,44.6],[-123.2,44.6],[-123.2,44.4]]].geo:area()   [-- about 5.3e8 --]
    coordinates geometry=>lst /m/math/geo/inst/coordinates 
    coordinates?lst<=geometry(){<j>}

    mapper the flattening: whatever the nesting depth, the points a geometry is ultimately made of one-to-one obj transformation (dom_c = rng_c = 1)

    the lhs geometry => every position it stores, in document order, as stamped \(\mathrm{geo{:}point}::T\) values

    geo:line::[[-123.13,44.47],[-121.18,45.61]].geo:coordinates()   [-- [geo:point::[-123.13,44.47],geo:point::[-121.18,45.61]] --]
    distance geometry=>meter /m/math/geo/inst/distance 
    distance?meter<=geometry(geometry::T){<j>}

    mapper the geodesic distance \(d(a,b)\), and \(0\) when the geometries intersect — a point inside a polygon is at distance zero, not at the distance to its nearest vertex one-to-one obj transformation (dom_c = rng_c = 1)

    sig: 
    the lhs geometry => the distance to the arg geometry as a \(\mathrm{meter}::T\)
    args: 
      geometry => 'the geometry to measure to'

    inside geometry=>geometry /m/math/geo/inst/inside 
    inside?geometry{?}<=geometry(#::T){<j>}

    the mirror of {@code has}: the same containment predicate, answering the CONTAINED object. \(a.inside(b) \iff b.has(a)\), but the two answer different subjects, and only this one returns the wrapper of a fibered rec

    sig: 
    the lhs geometry (the contained thing) => the lhs itself when it lies in the arg, otherwise \(\mathrm{noobj}\)
    args: 
      <#>::T => 'the container: a geometry, or a \(\mathrm{geo{:}bbox2d}::T\) envelope'
    examples: 
    geo:point::[-123.05,44.5].geo:inside(geo:bbox2d::[-123.2,44.4,-122.9,44.6])   [-- the point --]
    length geometry=>meter /m/math/geo/inst/length 
    length?meter<=geometry(){<j>}

    mapper the \(1\)-dimensional measure: the geodesic distance along each part's consecutive points; a point has length zero one-to-one obj transformation (dom_c = rng_c = 1)

    the lhs geometry => its measured length as a \(\mathrm{meter}::T\) — every polyline and every polygon boundary, summed geodesically
    examples: 
    geo:line::[[-123.13,44.47],[-121.18,45.61]].geo:length()   [-- meter::198845.05… (Portland to The Dalles) --]
    wkt geometry=>str /m/math/geo/inst/wkt 
    wkt?str<=geometry(){<j>}

    mapper the other string encoding — the one every spatial database's \(\mathrm{ST\_GeomFromText}\) takes. There is no \(\mathrm{wkt}::T\) document type to cast onto, so this is an instruction rather than an \(\mathrm{as}\) one-to-one obj transformation (dom_c = rng_c = 1)

    the lhs geometry => its Well-Known Text
    examples: 
    geo:point::[-123.13,44.47].geo:wkt()   [-- 'POINT (-123.13 44.47)' --]
