== Space

A **space** is a typed read/write storage system. Spaces maintain the `uri\<\=>obj` links that make up metatron's
distributed memory model. Every space is itself an `obj` — readable, writable, and navigable like any other address
in the system.

[discrete]
=== Types for Managing Impedance Mismatch

Every `space::T` is an `obj`, subject to metatron's https://en.wikipedia.org/wiki/Structural_type_system[structural
type system]. Two fields shape the contract of any space:

- **`root`** — a `type::T` constraining what can be written at document/row/vertex root depth. writes that fail the
  root type check are rejected before reaching the underlying storage system.
- **`schema`** — an `instset::T` holding the full vocabulary of types for this space. auto-discovered on connection
  for database spaces; defined explicitly for in-memory or file-based spaces.

[discrete,.center]
==== space routing

Spaces are registered in the router under the pattern declared in the space's `pattern` field. When metatron
evaluates `*mongo:users/123`, the router matches `mongo:#` to the registered `dcmntspace` and delegates the read.
The `/sys/space/` namespace (backed by `memspace`) holds the live space objects — `*sys/space/+` lists all mounted
spaces.
