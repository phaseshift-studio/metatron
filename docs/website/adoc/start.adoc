== Quick Start

++++
<img src="images/metatron-character-ansi.png" width="350px" style="float:right; margin:10px;"></a>
++++

**metatron** is an algebraically specified distributed virtual machine. **mtron** is a typed, self-referential language aimed directly at manipulating metatron.
The benefits of these two technologies are:

1. write applications that naturally exist outside/across the confines of a single machine.
2. process relational, graph, key-value, and document database from the same mtron perspective.
3. enjoy the elegance of the top-to-bottom ring theoretic approach to distributed data structures and processes.
* at minimum, enjoy a surprising number of "__huh. that's interesting.__"-moments.

The concepts herein are guaranteed to inspire even the most grizzled of computer scientists as they find themselves at times engaging with metatron's fractal-like formal theory and, at other times, noodling away on a cluster-oriented, data driven application using a bizarre, alien-like language that blurs numerous, long-standing schisms that have separated database query languages from application development languages, object-oriented encapsulation from functional fluidity, intra-net from internet, and mathematics from software engineering.
There is much to fathom within the wonderful world of metatron.

=== Install

A POSIX shell is all that is required.

[source,bash]
----
curl -fsSL https://metatron.phaseshift.studio/install.sh | bash
----

Or run it in a container...

[source,mtron]
----
docker run -d --name metatron -p 8555:8555 -p 8777:8777 \
  -v /var/run/docker.sock:/var/run/docker.sock \
  --group-add $(stat -c '%g' /var/run/docker.sock) \
  ghcr.io/phaseshift-studio/metatron:latest
----

\...with Docker compose.

[source,mtron]
----
curl -fsSLO https://metatron.phaseshift.studio/compose.yaml
METATRON_DOCKER_GID=$(stat -c '%g' /var/run/docker.sock) docker compose up -d
----

=== Basic Concepts

metatron evaluates mtron.
A one-off expression runs with `-e`.

[source,mtron]
----
$ bin/metatron -e "1-<[+2,+3]"
[3,4]
----

`1-<[...]` reads one object and applies two instructions to it, branching the one into two results — hence `[3,4]`.
Everything in mtron is built from two operators:
`*` composes instructions and `+` branches them.

The same two operators describe a running program: the code is a graph of instructions, and a **monad** walks it, carrying the current value — forking wherever the code branches.

=== The console

For interactive use, the console is a REPL with syntax highlighting, step-through compilation, and type checking.

[source,mtron]
----
$ bin/metatron
mtron>
----

A few expressions to try:

[source,mtron]
----
1 + 2
1-<[_,+2,*5]>-.sum()
[a=>1,b=>[c=>[5,6,7]]]>>b/c/1
----

To boot a headless instance from a boot file, pass it at startup.

[source,bash]
----
$ bin/metatron "[boot=>start.mtron,log=>info]"
----
