== Quick Start

metatron is a data-oriented virtual machine and its language, **mtron**. A row in a
database, a tag in an HTML page, a vertex in a graph, a value in memory on an IoT
device — all of it lives in one address space and is read and written through a
single referential model.

This page goes from nothing to a running REPL, then points at the parts of the
documentation worth reading next.

[discrete]
=== Install

A POSIX shell is all that is required.

[source,bash]
----
curl -fsSL https://metatron.phaseshift.studio/install.sh | bash
----

Or run it in a container.

[source,bash]
----
docker run -d --name metatron -p 8555:8555 -p 8777:8777 \
  -v /var/run/docker.sock:/var/run/docker.sock \
  --group-add $(stat -c '%g' /var/run/docker.sock) \
  ghcr.io/phaseshift-studio/metatron:latest
----

[source,bash]
----
curl -fsSLO https://metatron.phaseshift.studio/compose.yaml
METATRON_DOCKER_GID=$(stat -c '%g' /var/run/docker.sock) docker compose up -d
----

[discrete]
=== First expression

metatron evaluates mtron. A one-off expression runs with `-e`.

[source,bash]
----
$ bin/metatron -e "1-<[+2,+3]"
[3,4]
----

`1-<[...]` reads one object and applies two instructions to it, branching the one
into two results — hence `[3,4]`. Everything in mtron is built from two operators:
`*` composes instructions and `+` branches them.

The same two operators describe a running program: the code is a graph of
instructions, and a **monad** walks it, carrying the current value — forking wherever
the code branches.

=== The console

For interactive use, the console is a REPL with syntax highlighting,
step-through compilation, and type checking.

[source,bash]
----
$ bin/metatron
mtron>
----

A few expressions to try:

[source,mtron]
----
1 + 2
1-<[_,+2,*5]>-.sum()
[a=>1,b=>[c=>[5,6,7]]]>>b/c/1
----

To boot a headless instance from a boot file, pass it at startup.

[source,bash]
----
$ bin/metatron "[boot=>start.mtron,log=>info]"
----
